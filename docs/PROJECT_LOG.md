## 🔑 الخطوة التالية: الحصول على API تيليجرام

### الخطوات:

1. **اذهب إلى:** https://my.telegram.org/apps

2. **سجل دخول برقم هاتفك** (المستخدم في التيليجرام)

3. **أنشئ تطبيق جديد:**
   - App title: `StockAnalysis`
   - Short name: `stock`
   - Platform: `Desktop`

4. **انسخ البيانات:**
   - `api_id`: رقم مثل `12345678`
   - `api_hash`: نص مثل `a1b2c3d4e5f6...`

5. **أرسل لي البيانات** وسأضيفها للنظام
